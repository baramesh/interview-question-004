# AC-CP-01 — เกณฑ์ยอมรับการสร้างโปรไฟล์

| กรณี | ผลที่คาดหวัง |
|---|---|
| กดบันทึกเมื่อข้อมูลไม่ครบ | แสดงข้อผิดพลาดรายฟิลด์และไม่เรียก API |
| กรอกข้อมูลถูกต้องแล้วบันทึก | API ตอบ `201`, PostgreSQL มีระเบียนใหม่ และหน้าแสดง `save data success · ID: {id}` |
| กด Clear | ล้างค่า รูปตัวอย่าง ชื่อไฟล์ และข้อความแจ้ง |
| API ปฏิเสธข้อมูล | แสดงข้อความผิดพลาดและเก็บค่าที่กรอกไว้ |
| เปิดด้วยจอมือถือ | แบบฟอร์มเรียงหนึ่งคอลัมน์และใช้งานได้โดยไม่เลื่อนแนวนอน |
