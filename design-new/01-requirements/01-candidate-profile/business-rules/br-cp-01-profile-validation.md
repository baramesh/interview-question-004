# BR-CP-01 — กฎตรวจข้อมูลโปรไฟล์

| กฎ | รายละเอียด |
|---|---|
| BR-CP-01-01 | ทุกฟิลด์ต้องมีค่า |
| BR-CP-01-02 | `email` ต้องเป็นรูปแบบอีเมลและยาวไม่เกิน 254 ตัวอักษร |
| BR-CP-01-03 | `phone` ต้องมีตัวเลขเริ่มต้นและสิ้นสุด รวมความยาวที่รองรับ 9–20 ตัวอักษร |
| BR-CP-01-04 | `birthDate` ต้องเป็นวันที่อดีตในรูปแบบ `DD/MM/YYYY` |
| BR-CP-01-05 | `occupation` ต้องอยู่ในรายการที่ระบบกำหนด |
| BR-CP-01-06 | `sex` รับเฉพาะ `Male` หรือ `Female` |
| BR-CP-01-07 | รูปต้องเป็น PNG, JPEG, GIF หรือ WebP ขนาดไม่เกิน 2 MB และส่งเป็น Base64 data URL |
| BR-CP-01-08 | API ต้องตรวจข้อมูลซ้ำอีกครั้งก่อนเขียนฐานข้อมูล |
