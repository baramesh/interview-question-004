# FLW-CP-01 — ผู้สมัครสร้างโปรไฟล์

## Overview

ผู้สมัครกรอกข้อมูลครบ เลือกอาชีพจากข้อมูลหลัก เลือกรูปและบันทึก ระบบตรวจทั้งฝั่งหน้าเว็บและ API ก่อนสร้างระเบียนใน PostgreSQL

## Visible States

| state            | ความหมาย                         |
| ---------------- | -------------------------------- |
| empty            | แบบฟอร์มเริ่มต้น                 |
| editing          | ผู้สมัครกำลังกรอกข้อมูล          |
| validation-error | มีข้อมูลไม่ผ่านกฎ                |
| saving           | ปิดปุ่มและแสดงสถานะกำลังบันทึก   |
| saved            | แสดงข้อความสำเร็จและรหัสระเบียน  |
| save-error       | API หรือฐานข้อมูลบันทึกไม่สำเร็จ |

## Steps

| ลำดับ | ผู้กระทำ | การกระทำ                                                  | ผลลัพธ์                                                  |
| ----- | -------- | --------------------------------------------------------- | -------------------------------------------------------- |
| 1     | ผู้สมัคร | เปิดหน้าสร้างโปรไฟล์                                      | ระบบแสดงแบบฟอร์มว่างและดึงข้อมูลหลักอาชีพจาก API         |
| 2     | ผู้สมัคร | กรอกข้อมูลและเลือกรูป                                     | ระบบตรวจข้อมูลทันทีตามการโต้ตอบ                          |
| 3     | ผู้สมัคร | กด Save profile                                           | ระบบตรวจทุกฟิลด์                                         |
| 3.1   | ระบบ     | พบข้อมูลผิด                                               | แสดงข้อผิดพลาดและไม่ส่งข้อมูล                            |
| 4     | ระบบ     | ส่ง `POST /api/candidate-profiles` พร้อม `occupationCode` | API ตรวจข้อมูล จับคู่ข้อมูลหลักอาชีพ และเขียน PostgreSQL |
| 5     | ระบบ     | รับ `201 Created`                                         | แสดงข้อความสำเร็จพร้อม ID และล้างแบบฟอร์ม                |
