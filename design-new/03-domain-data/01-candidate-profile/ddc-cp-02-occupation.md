# DDC-CP-02 — Occupation Master Data

## ตาราง `occupations`

| Field         | ชนิด PostgreSQL        | ว่างได้ | เงื่อนไข                                                        |
| ------------- | ---------------------- | ------- | --------------------------------------------------------------- |
| id            | integer                | ไม่ได้  | PK, generated by default as identity; ใช้ภายในฐานข้อมูลเท่านั้น |
| code          | character varying(50)  | ไม่ได้  | unique; ค่าคงที่สำหรับสื่อสารผ่าน API เช่น `software-engineer`  |
| name          | character varying(100) | ไม่ได้  | ชื่อที่หน้าเว็บแสดง เช่น `Software Engineer`                    |
| display_order | integer                | ไม่ได้  | ลำดับการแสดงจากน้อยไปมาก                                        |
| is_active     | boolean                | ไม่ได้  | API ส่งเฉพาะค่า `true`                                          |

## ความสัมพันธ์

`Occupation` หนึ่งรายการสัมพันธ์กับ `CandidateProfile` ได้หลายระเบียนผ่าน `candidate_profiles.occupation_id` หน้าเว็บและ API ไม่เปิดเผย `id`; ใช้ `code` เป็นค่ารับส่งเท่านั้น
