# AC-PF-01 — เกณฑ์ยอมรับการสร้างโปรไฟล์

| กรณี                        | ผลที่คาดหวัง                                                                           |
| --------------------------- | -------------------------------------------------------------------------------------- |
| กดบันทึกเมื่อข้อมูลไม่ครบ   | แสดงข้อผิดพลาดรายฟิลด์และไม่เรียก API                                                  |
| กรอกข้อมูลถูกต้องแล้วบันทึก | API ตอบ `201`, PostgreSQL มีระเบียนใหม่ และ Toast แสดง `save data success · ID: {id}`  |
| กด Clear                    | ล้างค่า รูปตัวอย่าง ชื่อไฟล์ และปิด Toast ที่กำลังแสดง                                 |
| API ปฏิเสธข้อมูล            | แสดงข้อความผิดพลาดและเก็บค่าที่กรอกไว้                                                 |
| เปิดด้วยจอมือถือ            | แบบฟอร์มเรียงหนึ่งคอลัมน์และใช้งานได้โดยไม่เลื่อนแนวนอน                                |
| เปิดหน้าสร้างโปรไฟล์        | หน้าเรียก `GET /api/occupations` และแสดงชื่ออาชีพจากข้อมูลหลักตามลำดับ                 |
| ตรวจข้อความ production      | ไม่แสดงรหัสข้อสอบ ข้อมูลบุคคลทดสอบ ตัวอักษรย่อภายใน หรือข้อความที่ซ้ำ/ทวนชื่อหมวด      |
| เลือกอาชีพแล้วบันทึก        | payload ส่ง `occupationCode`; PostgreSQL เก็บ `occupation_id` ที่สัมพันธ์กับข้อมูลหลัก |
