# BR-PF-01 — กฎตรวจข้อมูลโปรไฟล์

| กฎ          | รายละเอียด                                                                                                      |
| ----------- | --------------------------------------------------------------------------------------------------------------- |
| BR-PF-01-01 | ทุกฟิลด์ต้องมีค่า                                                                                               |
| BR-PF-01-02 | `email` ต้องเป็นรูปแบบอีเมลและยาวไม่เกิน 254 ตัวอักษร                                                           |
| BR-PF-01-03 | `phone` ต้องมีตัวเลขเริ่มต้นและสิ้นสุด รวมความยาวที่รองรับ 9–20 ตัวอักษร                                        |
| BR-PF-01-04 | `birthDate` ต้องเป็นวันที่อดีตในรูปแบบ `DD/MM/YYYY`                                                             |
| BR-PF-01-05 | `occupationCode` ต้องตรงกับข้อมูลหลักอาชีพที่มีสถานะใช้งาน                                                      |
| BR-PF-01-06 | `sex` รับเฉพาะ `Male` หรือ `Female`                                                                             |
| BR-PF-01-07 | รูปต้องเป็น PNG หรือ JPEG ขนาดไม่เกิน 2 MB ส่งเป็น Base64 data URL และ byte signature ต้องตรงกับ MIME ที่ประกาศ |
| BR-PF-01-08 | API ต้องตรวจข้อมูลซ้ำอีกครั้งก่อนเขียนฐานข้อมูล                                                                 |
