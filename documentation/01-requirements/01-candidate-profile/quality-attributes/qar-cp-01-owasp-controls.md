# QAR-CP-01 — ข้อกำหนด OWASP ที่อยู่ในขอบเขต

การยืนยันตัวตนและการกำหนดสิทธิ์ไม่อยู่ในข้อกำหนดต้นทาง ระบบจึงคงการสร้างโปรไฟล์แบบสาธารณะสำหรับข้อสอบ และต้องใช้มาตรการป้องกัน OWASP อื่นตามตารางนี้

| รหัส         | ข้อกำหนด                                                                                                       | เกณฑ์ตรวจยืนยัน                                                |
| ------------ | -------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| QAR-CP-01-01 | API ต้องตรวจว่า byte signature ของ PNG, JPEG, GIF หรือ WebP ตรงกับ MIME ที่ประกาศ                              | MIME กับ byte ไม่ตรงกันต้องตอบ `400` และไม่เขียนข้อมูล         |
| QAR-CP-01-02 | reverse proxy และ API ต้องปฏิเสธ request body ที่เกิน 3 MiB ก่อนประมวลผล                                       | คำขอเกินเพดานต้องตอบ `413`                                     |
| QAR-CP-01-03 | `POST /api/candidate-profiles` ต้องจำกัด 20 คำขอต่อหนึ่ง IP ในช่วงเวลา 1 นาที และไม่เข้าคิว                    | คำขอที่เกินต้องตอบ `429`                                       |
| QAR-CP-01-04 | คำตอบผ่าน Nginx ต้องมี CSP, MIME sniffing protection, frame protection, referrer policy และ permissions policy | ตรวจ header จากหน้าเว็บและ API ผ่านพอร์ต `4204`                |
| QAR-CP-01-05 | พอร์ตของ client, API และ PostgreSQL สำหรับการทดสอบต้องผูกกับ loopback ของเครื่องเท่านั้น                       | `docker compose config` แสดง host IP เป็น `127.0.0.1`          |
| QAR-CP-01-06 | ข้อผิดพลาดที่ไม่คาดหมายต้องตอบ Problem Details พร้อม `traceId` โดยไม่เปิดเผย stack trace, SQL หรือข้อมูลลับ    | ตรวจการตั้งค่าและกรณีผิดพลาดในสภาพแวดล้อมที่ไม่ใช่ Development |
| QAR-CP-01-07 | ห้ามบันทึก request body, Base64, ข้อมูลส่วนบุคคล หรือ credential ลง log                                        | ตรวจรหัสและ log โดยใช้ข้อมูลทดสอบที่ไม่ใช่ข้อมูลบุคคลจริง      |

เพดาน 3 MiB รองรับรูปที่ถอดรหัสแล้วไม่เกิน 2 MiB รวมส่วนขยาย Base64 และ JSON โดยยังหยุดคำขอขนาดผิดปกติก่อนเข้าสู่ตรรกะธุรกิจ
