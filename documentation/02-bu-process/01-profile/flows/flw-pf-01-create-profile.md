# FLW-PF-01 — ผู้กรอกแบบฟอร์มสร้างโปรไฟล์

## Overview

ผู้กรอกแบบฟอร์มกรอกข้อมูลครบ เลือกอาชีพจากข้อมูลหลัก เลือกรูปและบันทึก ระบบตรวจทั้งฝั่งหน้าเว็บและ API ก่อนสร้างระเบียนใน PostgreSQL

## Visible States

| state            | ความหมาย                         |
| ---------------- | -------------------------------- |
| empty            | แบบฟอร์มเริ่มต้น                 |
| editing          | ผู้กรอกแบบฟอร์มกำลังกรอกข้อมูล   |
| validation-error | มีข้อมูลไม่ผ่านกฎ                |
| saving           | ปิดปุ่มและแสดงสถานะกำลังบันทึก   |
| saved            | แสดง Toast สำเร็จพร้อมรหัสระเบียน |
| save-error       | API หรือฐานข้อมูลบันทึกไม่สำเร็จ |

## Steps

| ลำดับ | ผู้กระทำ        | การกระทำ                                        | ผลลัพธ์                                                  |
| ----- | --------------- | ----------------------------------------------- | -------------------------------------------------------- |
| 1     | ผู้กรอกแบบฟอร์ม | เปิดหน้าสร้างโปรไฟล์                            | ระบบแสดงแบบฟอร์มว่างและดึงข้อมูลหลักอาชีพจาก API         |
| 2     | ผู้กรอกแบบฟอร์ม | กรอกข้อมูลและเลือกรูป                           | ระบบตรวจข้อมูลทันทีตามการโต้ตอบ                          |
| 3     | ผู้กรอกแบบฟอร์ม | กด Save profile                                 | ระบบตรวจทุกฟิลด์                                         |
| 3.1   | ระบบ            | พบข้อมูลผิด                                     | แสดงข้อผิดพลาดและไม่ส่งข้อมูล                            |
| 4     | ระบบ            | ส่ง `POST /api/profiles` พร้อม `occupationCode` | API ตรวจข้อมูล จับคู่ข้อมูลหลักอาชีพ และเขียน PostgreSQL |
| 5     | ระบบ            | รับ `201 Created`                               | แสดง Toast ของ Angular Material พร้อม ID และล้างแบบฟอร์ม |
