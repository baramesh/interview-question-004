# SV-PF-01 — ขอบเขตความมั่นคงปลอดภัยของระบบทดสอบ

| ประเด็น        | กฎ                                                                                                                                |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| การเข้าถึง     | โจทย์ไม่กำหนดการพิสูจน์ตัวตน API จึงเป็น public ในรุ่นทดสอบและห้ามนำไปเปิดภายนอกโดยไม่เพิ่ม access control                        |
| การตรวจข้อมูล  | Client ช่วยผู้ใช้ ส่วน API เป็นผู้บังคับกฎสุดท้าย                                                                                 |
| รูปภาพ         | จำกัดชนิดและขนาด 2 MB ตรวจ byte signature ให้ตรงกับ MIME ก่อนเก็บ Base64; ยังไม่มีการสแกน malware                                 |
| การใช้ทรัพยากร | Nginx และ API จำกัด request 3 MiB; endpoint สร้างข้อมูลจำกัด 20 คำขอต่อหนึ่ง IP ใน 1 นาที                                         |
| ฐานข้อมูล      | PostgreSQL อยู่ในเครือข่าย Docker และพอร์ตทดสอบ `5434` ผูกกับ `127.0.0.1` เท่านั้น                                                |
| เครือข่าย      | พอร์ต client, API และ PostgreSQL ที่ publish ผูกกับ loopback; ไม่ถือเป็นแบบ deploy สำหรับ production                              |
| รหัสผ่าน       | `.env` ถูกละเว้นจาก git; ค่าใน `.env.example` และ `appsettings.json` เป็นข้อมูลทดสอบท้องถิ่นและห้ามใช้จริง                        |
| ข้อผิดพลาด     | API ใช้ Problem Details พร้อม `traceId`; หน้าเว็บแสดงข้อความทั่วไปและไม่เปิดเผย connection string, stack trace หรือรายละเอียด SQL |

รุ่นนี้ไม่เหมาะกับ production รายละเอียดการจับคู่ OWASP และเงื่อนไขปิดช่องว่างอยู่ใน `SV-PF-02`
