# SV-CP-01 — ขอบเขตความมั่นคงปลอดภัยของระบบทดสอบ

| ประเด็น       | กฎ                                                                                                                                             |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| การเข้าถึง    | โจทย์ไม่กำหนดการพิสูจน์ตัวตน API จึงเป็น public ในรุ่นทดสอบและห้ามนำไปเปิดภายนอกโดยไม่เพิ่ม access control                                     |
| การตรวจข้อมูล | Client ช่วยผู้ใช้ ส่วน API เป็นผู้บังคับกฎสุดท้าย                                                                                              |
| รูปภาพ        | จำกัดชนิดและขนาด 2 MB ก่อนเก็บ Base64; ไม่ประมวลผลเนื้อหารูปเพิ่มเติม                                                                          |
| ฐานข้อมูล     | PostgreSQL อยู่ในเครือข่าย Docker แต่ compose ยัง publish พอร์ต `5434` ทุก host interface จึงเป็นข้อจำกัดของรุ่นทดสอบ ไม่ใช่ security boundary |
| รหัสผ่าน      | `.env` ถูกละเว้นจาก git; ค่าใน `.env.example` และ `appsettings.json` เป็นข้อมูลทดสอบท้องถิ่นและห้ามใช้จริง                                     |
| ข้อผิดพลาด    | หน้าเว็บแสดงข้อความทั่วไปและไม่เปิดเผย connection string หรือรายละเอียด SQL                                                                    |

รุ่นนี้ไม่เหมาะกับ production รายละเอียดการจับคู่ OWASP และเงื่อนไขปิดช่องว่างอยู่ใน `SV-CP-02`
