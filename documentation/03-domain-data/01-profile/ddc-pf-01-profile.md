# DDC-PF-01 — Profile

| Field          | ชนิด PostgreSQL          | ว่างได้ | เงื่อนไข                                              |
| -------------- | ------------------------ | ------- | ----------------------------------------------------- |
| id             | integer                  | ไม่ได้  | PK, generated by default as identity                  |
| first_name     | character varying(100)   | ไม่ได้  | ชื่อ                                                  |
| last_name      | character varying(100)   | ไม่ได้  | นามสกุล                                               |
| email          | character varying(254)   | ไม่ได้  | เก็บอักษรเล็ก                                         |
| phone          | character varying(30)    | ไม่ได้  | คงรูปแบบที่ผู้ใช้กรอกหลัง trim                        |
| profile_base64 | text                     | ไม่ได้  | Base64 data URL ของรูปไม่เกิน 2 MB                    |
| birth_date     | date                     | ไม่ได้  | วันที่อดีต                                            |
| occupation_id  | integer                  | ไม่ได้  | FK → `occupations.id`; API จับคู่จาก `occupationCode` |
| sex            | character varying(20)    | ไม่ได้  | `Male` หรือ `Female`                                  |
| created_at_utc | timestamp with time zone | ไม่ได้  | เวลาสร้างแบบ UTC                                      |

## ความสัมพันธ์

`profiles.occupation_id` มีความสัมพันธ์ many-to-one กับข้อมูลหลัก `Occupation` ตาม `DDC-PF-02` และใช้ `ON DELETE RESTRICT`
