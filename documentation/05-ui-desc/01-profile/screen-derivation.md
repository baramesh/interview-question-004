# การได้มาของหน้าจอ Profile

| ความสามารถจากข้อกำหนด | state ที่ผู้ใช้เห็น                                         | เจ้าของหน้าจอ | เหตุผล                                           |
| --------------------- | ----------------------------------------------------------- | ------------- | ------------------------------------------------ |
| สร้างโปรไฟล์          | empty, editing, validation-error, saving, saved, save-error | `UIS-PF-01`   | ทุก state เกิดในแบบฟอร์มเดียวและไม่มีเส้นทางอื่น |

ระบบมีหนึ่งหน้าจอ ไม่มีหน้า list/detail เพราะโจทย์กำหนดเฉพาะการสร้างระเบียน
