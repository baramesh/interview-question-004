# UIX-CP-01 — พฤติกรรมหน้าสร้างโปรไฟล์

| เหตุการณ์       | เงื่อนไข                    | พฤติกรรม                                                  |
| --------------- | --------------------------- | --------------------------------------------------------- |
| เลือกรูป        | ชนิดและขนาดถูกต้อง          | อ่านเป็น Base64 แสดงตัวอย่างและชื่อไฟล์                   |
| เลือกรูป        | ชนิดไม่รองรับหรือเกิน 2 MB  | ไม่เก็บค่าและแสดงข้อผิดพลาด                               |
| เปิดหน้า        | API ข้อมูลหลักสำเร็จ        | เติมรายการอาชีพด้วย `name` และเก็บ `code` เป็นค่าที่เลือก |
| เปิดหน้า        | API ข้อมูลหลักล้มเหลว       | แสดงข้อผิดพลาดการโหลดอาชีพและไม่สร้างรายการสำรองใน Client |
| กด Save profile | แบบฟอร์มผิด                 | ทำเครื่องหมายทุกฟิลด์และไม่เรียก API                      |
| กด Save profile | แบบฟอร์มถูก                 | ปิดปุ่ม แสดงตัวหมุน และเรียก API โดยส่ง `occupationCode`  |
| API สำเร็จ      | ได้ `201`                   | แสดงข้อความพร้อม ID แล้วล้างแบบฟอร์ม                      |
| API ล้มเหลว     | ไม่ได้ `201`                | แสดงข้อผิดพลาด เปิดปุ่ม และคงข้อมูล                       |
| กด Clear        | ทุก state ที่ไม่กำลังบันทึก | ล้างข้อมูล รูป ชื่อไฟล์ และข้อความแจ้ง                    |
